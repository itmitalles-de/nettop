# Public site assets

`nettop-demo.png`, `nettop-setup.png`, `nettop-sort.png` and `nettop-demo.mp4`
show the actual nwtop terminal UI in explicit `--demo` mode. Traffic, addresses
and process rows are synthetic. The asset filenames retain the former project
name; the terminal views contain no old product branding. The recording demonstrates monitoring, F2 Setup
and F6 sorting. These are deliberate public product assets, not live traffic
captures or desktop screenshots.

`mark.svg`, `readme-banner.svg` and `badge-*.svg` are original vector artwork. `social-card.png`
is a browser render of `social-card.html` at 1200 × 630 pixels. It combines
the product branding with the DEMO terminal image. Project artwork is
covered by the repository's license, GPL-3.0-or-later.

The fonts in `fonts/` are self-hosted Chivo and IBM Plex Mono. Their source URLs
and SIL Open Font License notices are included in that directory.
